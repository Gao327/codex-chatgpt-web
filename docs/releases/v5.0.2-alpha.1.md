# v5.0.2-alpha.1 — fork security release

This is an **alpha prerelease** for evaluation, not a stable release. Download it manually from this fork. The application currently checks GitHub's latest stable release endpoint, so this alpha is not offered by the in-app updater.

This release packages the security and privacy fixes maintained in `Gao327/codex-chatgpt-web`.

## Changes

- Fix quitting during pending login and closing the application before setup is complete; cancel pending passkey processes during shutdown.
- Authenticate the local browser automation gateway and local API, and restrict profile-wide cookie/cache operations.
- Enforce request tool constraints and keep private continuation state in memory.
- Make browser diagnostics containing page content opt-in.
- Restrict application updates and installers to this fork, including release asset validation and SHA-256 checks. There is no upstream fallback.
- Update Hono and js-yaml to address the advisories identified during review.

## Installation and update source

- Apple silicon Mac: use the `mac-arm64.dmg`; the matching ZIP is used by the updater.
- Windows x64: use the `win-x64.exe` installer.
- Linux packages are excluded from this release. The Linux browser smoke test still fails during screenshot capture with a zero-width surface under Xvfb. Do not treat the Linux build as validated.
- Existing upstream builds must be replaced manually with a build from this fork before relying on fork-only updates. This release does not modify an already-installed upstream application's updater remotely.

## Validation and limitations

The Mac and Windows job results are recorded in the linked GitHub Actions release run. The overall run is failed because Linux failed, and automatic publication was skipped. A dedicated publication workflow assembles this alpha only from successful Mac and Windows job artifacts from the tagged commit. These checks do not establish successful use of a real ChatGPT account.

Current real-account validation remains incomplete, including login/MFA, Browser-only and Full-mode turns, model discovery, compaction, cancellation, Voice, session reuse, and upgrade preservation. The historical upstream v3.0.0 validation is not evidence for this fork release. Use a separate test profile for evaluation; retain your existing installer and configuration backup for recovery. Report failures without sharing cookies, tokens, prompts, or other private account data.

macOS packages use ad hoc signing and are not Apple-notarized. Windows publisher signing is not configured. This release must not be described as certified safe or free of unknown vulnerabilities.

Linux AppImages require permission to create unprivileged user namespaces for Electron sandboxing. The disposable Ubuntu CI runner explicitly enables this; default Ubuntu AppArmor settings may block startup on an unconfigured desktop. Linux desktop installation under those defaults has not been validated. Do not bypass this by disabling Electron's sandbox.
